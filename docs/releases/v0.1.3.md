Trainlog v0.1.3 improves the local-first capture, planning, history, and
synchronization experience without changing the published data formats.

## Highlights

- The Android interface is more compact while preserving durable capture.
- Programs and their execution state are available across the supported local
  workflows.
- Sessions and durable drafts are clearer to inspect and resume.
- The Web exercise catalogue supports bounded administration workflows.
- Causal deletion prevents retired data from being resurrected by replay.
- Full-generation synchronization carries the complete supported state.
- Direct MTP exchange is more robust and reports bounded failures precisely.
- Foreground and background synchronization have explicit conversation
  ownership.
- Full-generation requests use a dedicated trigger while legacy V3 signalling
  remains separate and strict.

## Assets

- `trainlog-android-v0.1.3.apk`: signed public Android APK.
- `trainlog-tui-linux-x86_64-v0.1.3`: Linux x86-64 runtime bundle containing
  the TUI, local Web adapter, synchronization helpers, and required catalogs.
- `SHA256SUMS`: SHA-256 checksums for both artifacts.

Trainlog v0.1.1 is the latest stable release before Web implementation began.

## Interfaces and languages

- French is the default interface language on Android and in the TUI, with
  English selectable and a persistent local preference.
- BODY ZONE labels and synchronization states are presented locally without
  changing business data or exchange formats.
- Android workflows for entering, correcting, and reordering active and
  completed sessions are improved.

## Reliability

- Transactional corrections and regression coverage protect corrected and
  synchronized sessions.
- Decimal input accepts `.` or `,`, rejects non-finite values, and preserves
  intermediate editing states.
- The Android APK was built with Trainlog's durable signing identity and
  verified before publication.

## Architecture

- The `TRAINLOG_WEB_V1` contract is frozen: the future Web interface is a local
  sibling adapter built on typed Trainlog Core services.
- No Web server, frontend, or Dashboard is implemented in this release.

## Assets

- `trainlog-android-v0.1.1.apk`: signed Android APK.
- `trainlog-tui-linux-x86_64-v0.1.1`: dynamically linked Linux x86-64
  executable.
- `SHA256SUMS`: SHA-256 checksums for both artifacts.
